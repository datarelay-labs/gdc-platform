# DATA RELAY GOVERNANCE WORKSPACE UX CHARTER
Version 1.0

Status: Proposed Architecture

==================================================
PURPOSE
==================================================

This document defines the UX architecture for the Governance Workspace within the Data Relay Stream Wizard.

The purpose of Governance is NOT to expose governance engines.

The purpose of Governance is to allow users to define:

- What data requires protection
- How that data should be protected
- What should happen when protected data is detected

Governance must remain:

- Optional
- Stream-centric
- Business intent driven

==================================================
PRODUCT POSITIONING
==================================================

Data Relay is:

Enterprise Data Control Gateway

Governance is:

Optional Data Control Capability

Governance is NOT:

- Compliance Platform
- DLP Product
- Policy Management Platform
- Governance Product
