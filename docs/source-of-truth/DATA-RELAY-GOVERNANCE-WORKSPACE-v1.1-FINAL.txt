==================================================
ACCEPTANCE CRITERIA
==================================================

1.

User can switch between

Enrichment

and

Data Protection

without leaving Step 4.

--------------------------------------------------

2.

User can create governance rule
for any mapped field.

--------------------------------------------------

3.

User can preview transformation effect.

--------------------------------------------------

4.

User never sees internal engine names.

--------------------------------------------------

5.

Deploy shows governance summary.

--------------------------------------------------

6.

Wizard remains 5-step Destination First architecture
(Connect → Sample & Record Selection → Destinations → Route Processing → Deploy).

--------------------------------------------------

7.

No existing enrichment functionality breaks.

Status note (P1-3): Wizard step count is 5-step Destination First. See STREAM-WIZARD-UX-CHARTER v5.2.
