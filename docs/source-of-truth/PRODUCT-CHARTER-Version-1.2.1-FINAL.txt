Product Definition
==================================================

Data Relay는

Data Delivery Gateway

+

Optional Data Protection

제품이다.

--------------------------------------------------

사용자의 주요 목적

1. 데이터를 수집한다

2. 데이터를 변환한다

3. 데이터를 목적지로 전달한다

4. 데이터 전달 상태를 확인한다

5. 필요 시 데이터를 보호한다

--------------------------------------------------

Data Relay는

데이터 전달(Data Delivery)과
데이터 통제(Data Control)를 위한 제품이다.

--------------------------------------------------

Data Relay는

Identity Platform이 아니다.

Data Relay는

Enterprise IAM 제품이 아니다.

--------------------------------------------------

Data Relay의 기본 Delivery Architecture는

One Stream
↓
Many Routes
↓
Many Destinations

이다.

--------------------------------------------------

사용자 흐름은

Collect Data
↓
Select Destinations
↓
Configure Route Processing
↓
Deploy

이다.

==================================================
Architecture Guardrails
==================================================

새로운 기능은 반드시 아래 조건을 충족해야 한다.

1.

Core Pipeline 내에서 동작해야 한다.

2.

기존 Stream Runtime을 재사용해야 한다.

3.

Data Control 또는 Data Delivery 목적이어야 한다.

4.

Enterprise IAM 방향으로 확장되어서는 안 된다.

5.

제품 정체성(Data Control Gateway)을 훼손해서는 안 된다.

6.

Route Processing Model과 충돌해서는 안 된다.

7.

Destination별 처리를 위해 Stream 복제를 요구해서는 안 된다.
